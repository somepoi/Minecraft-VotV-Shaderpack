# Minecraft VotV Shaderpack

Шейдерпак для **Minecraft 1.20.1 Forge** с **Oculus + Embeddium**. Проект переносит выбранные эффекты *Voices of the Void* и Quake-подобную воду в один устанавливаемый shaderpack. Ресурспак не требуется.

## Что входит

- Волновая, пикселизированная вода в духе Software Renderer из Half-Life, с картой поверхности из VotV.
- Камерное квантование цвета и настраиваемый дизеринг по маске VotV.
- Подводное искажение и окрашивание.
- Точечная выборка текстур без экранного размытия.
- Без VotV-неба, облаков и отдельных теневых эффектов.

Подробности реализации и статус тестирования: [STATUS_RU.md](STATUS_RU.md). Исследовательские материалы и исходные карты хранятся отдельно от готового shaderpack.

## Установка

1. Скачай ZIP shaderpack из [последнего релиза](https://github.com/somepoi/Minecraft-VotV-Shaderpack/releases/latest), когда он будет опубликован.
2. Не распаковывая ZIP, помести его в папку `shaderpacks` профиля Minecraft.
3. В настройках Oculus выбери **Minecraft VotV Shaderpack**.

Для обычного использования нужны Minecraft 1.20.1 Forge, Oculus и Embeddium. Игровая совместимость этой версии пока не подтверждена запуском в Minecraft; см. статус выше.

## Настройки

Параметры эффектов доступны в меню настроек шейдерпака Oculus. Сборка по умолчанию включает Quake-воду, дизеринг, квантование цвета и подводный эффект.

## Сборка из исходников

Нужен Python 3.10 или новее. Установи зависимость и запусти сборку:

```powershell
python -m pip install -r requirements-build.txt
python tools/build.py
```

Готовый shaderpack и архив исходников появятся в `dist/`. Версию можно указать явно, как в теге релиза, например `python tools/build.py --version 1.2.3`. Для проверки, что сгенерированные файлы соответствуют исходникам:

```powershell
python tools/build.py
git diff --exit-code
```

## Структура

- `shaders/` — исходники и файлы shaderpack.
- `assets/source-normals/` — исходные карты нормалей воды, используемые генератором атласа.
- `research/` — исследовательские материалы VotV.
- `tools/build.py` — сборка атласа, файлов совместимости и архивов.
- `SOURCE_ASSETS.json`, `NORMAL_TEXTURES.json`, `SHADERS.sha256` — происхождение ресурсов и контрольные суммы.
