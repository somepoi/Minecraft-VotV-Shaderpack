# VotV Quake 1.0.0

Отдельный shaderpack для Minecraft 1.20.1 Forge + Oculus + Embeddium. В поставке только shaderpack; ресурспак не нужен.

Вода использует волновое поле 128×128 по модели Half-Life Software Renderer: импульсы, распространение и затухание волны, смещение выборки. Для рисунка поверхности сохраняется точечная выборка извлечённой normal map VotV; sin/cos-анимация её OpenGL-материала не используется. Восстановленный `mat_gldsrcQuakeWater` с двумя движущимися sin/cos UV-выборками из OpenGL варианта не используется в качестве алгоритма анимации.

Камерные эффекты VotV взяты из восстановленного `PP_main`: настраиваемое квантование цвета и дизеринг по извлечённой маске VotV 40×4; отдельные настройки числа уровней, включения и силы дизеринга, яркости; подводное радиальное искажение и синеватая окраска.

Специальное небо VotV, облака VotV, сезонная палитра, тени и специальные фильтры текстур исключены. Обычное небо Minecraft остаётся без замены; облака/солнце/луна в параметрах пака отключены. Текстуры блоков, моделей, предметов и частиц выбираются точечными выборками без билинейного/трилинейного сглаживания. Вода и нормальная карта VotV тоже читаются без билинейной интерполяции. Экранное искажение камеры — отдельный постэффект. Все эффекты поставляются одним shaderpack.

Установка: положи `VotV-Quake-1.0.0.zip` без распаковки в `shaderpacks` своего Minecraft-профиля и выбери в меню Oculus. DEFAULT включает Quake-воду, 16 уровней цвета, дизеринг полной силы и подводное искажение.

`VotV Quake` здесь — перенос ПО water wave-field behavior в водный проход Minecraft с VotV-картой поверхности и камерными эффектами VotV. Это не прямой порт Unreal material graph. В игре с Oculus этот новый вариант ещё не запускался.
