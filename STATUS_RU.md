# Статус Minecraft VotV Shaderpack 1.0.0

Собран shaderpack с программной водной сеткой и выбранными эффектами камеры VotV. Проверка игровых сценариев не запускалась. Достоверность настройки шейдеров Oculus подтверждена здесь только по чтению исходников и документации; Minecraft + Forge + Oculus + Embeddium с этим новым паком не запускался. Внешний вид и FPS внутри игры пока неизвестны.
